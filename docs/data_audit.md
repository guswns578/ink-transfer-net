# 리터치 전후 대응 데이터 감사 (2026-10-03)

작가가 생성 이미지를 실제로 리터치한 결과물과 원래 생성 이미지를 자동으로 짝지은 후보 데이터 169쌍을 검사했습니다. 학습은 하지 않았고 원본은 수정하지 않았습니다.

## 수량과 통계

| 항목 | 값 |
|---|---|
| 쌍 수 (회차별) | 27 / 21 / 49 / 42 / 30 = 169 |
| 매칭 겹침 0.8 이상 | 58쌍 (0.85 이상 31쌍) |
| 대안 후보가 있는 컷 | 66개 |
| 생성 이미지 → 컷 축소 배율 | 중앙값 0.585 (0.179 ~ 0.917) |
| 컷 대비 유효 영역 비율 | 중앙값 0.82 (최소 0.07) |
| 어두운 픽셀(128 미만) 수, 정답/생성 비율 | 중앙값 1.759, 169쌍 중 167쌍에서 정답 쪽이 더 많음 |

어두운 픽셀 비율은 선 굵기 비율이나 순수 리터치 추가량이 아닙니다. 배경, 먹칠, 다시 그린 부분, 정렬 차이가 모두 섞여 있습니다.

## 핵심 문제

1. 리터치 결과가 독립된 선화 레이어가 아니라 배경·메모·컷 테두리가 섞인 합성 원고의 크롭입니다.
2. 같은 쌍 안에 선 굵기 정돈, 목 먹칠, 얼굴·의상의 국소 재작화, 의상 구조 변경이 함께 들어 있습니다.
3. CLIP 후보 → SIFT/RANSAC 유사변환 → 겹침 최고값 선택은 **대응 후보 탐색**일 뿐, 실제 리터치에 쓰인 생성 버전을 증명하지 않습니다.
4. 겹침 점수는 축소 해상도에서 3px 허용, 생성 잉크 주변으로 제한해 계산했습니다. 원본 해상도 정렬 정밀도가 아닙니다.
5. 저장된 쌍은 유효 영역의 외접 사각형이라, 회전 후 입력이 없는 영역이 포함될 수 있습니다. 유효 마스크를 따로 저장해야 합니다.
6. 쌍만으로는 컷 안에서의 인물 크기를 복원할 수 없어, 원래 컷의 크기·위치·배율 정보를 함께 보관해야 합니다.

## 권장 순서

1. 같은 회차의 원본 작업 파일(레이어 포함)에서 인물 선화 레이어만, 리터치 전후를 같은 캔버스로 내보낼 수 있는지 먼저 확인합니다. 가능하면 자동 매칭보다 우선합니다.
2. 정답이 확보되면 전역 배치·배율만 정렬하고, 유효 / 보호 / 재작화 제외 영역 마스크를 만듭니다. 비선형 정렬로 실제 수정을 지우지 않습니다.
3. 쌍 단위가 아니라 영역 단위로 분류합니다: 선·농도 정돈 / 먹칠·국소 보완 / 얼굴·의상·구조 재작화 / 입력에 없는 배경·인물.
4. 첫 학습은 선 형태가 대응하는 영역의 농도·선폭·끝선·소규모 잉크 가감만 감독합니다. 재작화·배경 영역은 손실에서 제외하고, 수정이 없는 정상 패치도 포함합니다.
5. 모델은 원본 잉크를 그대로 통과시키고 보정량만 예측하는 작은 residual U-Net, 초기 출력은 identity로 시작합니다.
6. 기준선(그대로 출력, 고정 농도 보정, 보수적 두께 보정)과 비교하고, 학습 영역 8~12개 재현을 먼저 확인한 뒤 회차 단위 미학습 평가로 넓힙니다. 초안 분할: 앞 3회차 97쌍 학습 / 4회차 42쌍 검증 / 5회차 30쌍 시험.
7. 평가는 정상 선 삭제, 국소 선 변위, 선량·폭·먹칠의 적절성, 원래 출력 크기에서의 인물별 품질, 실제 리터치 시간으로 합니다. 전체 PSNR/MAE만으로 판정하지 않습니다.

## 판정

유망한 대응 후보 데이터지만, 169쌍 전체를 정답으로 그대로 학습하는 것은 권장하지 않습니다. **네트워크를 고르기 전에 깨끗한 정답과 실제 리터치 전 버전을 확보하는 것이 우선**입니다.
